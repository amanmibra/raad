# Changelog

## 0.1.0

First implementation: validated commit-pinned Git data mounts, partial remote fetch, offline snapshots, GitHub proposal/direct-write adapters, Rust embedding, CLI, and local stdio MCP. Includes human/agent documentation, SOP fixtures, security tests, and a synthetic monorepo benchmark. Live private writes and platform limits are documented in the verification record.

Native Python and TypeScript SDKs embed the Rust core. Prebuilt SDK packages, CLI archives, MCP bundles, and checksums are distributed through GitHub Releases for Linux x86-64 and Apple Silicon macOS. SDKs are also distributed through PyPI and npm.
